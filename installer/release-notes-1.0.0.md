**Clipshaper 1.0.0: the first release.** Long video in, short clips out. Free, no watermark, nothing uploaded.

- **Finds the best moments:** every word is written down, then a local AI model reads the transcript like an editor and ranks each clip out of 10.
- **Follows the speaker:** wide videos become 9:16, with the frame tracking faces and cutting with the video. Or pick Centre / Whole frame.
- **Captions:** 9 word-by-word styles, burned in.
- **Paste a link:** YouTube, TikTok, Instagram, X, Twitch, Facebook, Vimeo and more. Only use videos you own or have permission to use.
- **Trim to the word**, rename, remove, and export one clip or all of them as 1080×1920 MP4.

First run downloads two models (speech 574 MB, moment finder 1.9 GB). If you already use Captionshaper or Writeshaper, Clipshaper reuses them.

Mac: Apple silicon, macOS 12+. First time: right-click the app, Open. Windows 10/11 64-bit: SmartScreen may warn; click More info, Run anyway.

Or try it without installing: https://hollowbit.dev/clipshaper/try/
